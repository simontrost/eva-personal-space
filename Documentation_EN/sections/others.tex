\subsection{Testing and troubleshooting}
\file{verify_backend.py} checks packages, CUDA and model files. The 14 checks
in \file{test_response_language.py}, \file{test_voice_preview.py} and
\file{test_streaming_transcription.py} use simulated models and do not record
audio. Run \file{test_voice_profiles.py} outside Play
for real voice synthesis and reusable test WAVs. It also exercises Ramona's
phoneme compatibility fix.

With the backend already ready, \file{test_live_voice_preview.py} checks all four
short previews, cached results, audio formats and signal. Then
\file{test_live_voice_profiles.py} uses the generated WAVs to check the complete
Whisper/Ollama/Piper path. These clients use their own connections and do not
play test audio through Unity.

Unity's \menu{EVA > Interface > Validate Selection Menu} checks references in
Edit mode. In Play, with the menu open, it checks all 72 design/style/language/voice
combinations, recording gates and both preview renderers. Stop a running preview
before this check. Other retained appearance/gaze tools remain under
\menu{EVA > Appearance}, \menu{EVA > Gaze} and \menu{EVA > Diagnostics}.

Errors: \file{Backend/backend-runtime.log} (1 MB plus one backup).
Stop Play before edits. Unity closes only the process trees it started.
