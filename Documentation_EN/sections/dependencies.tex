\smalltitle{Model and voice settings}
\begin{itemize}
\item \textbf{Recognition:} Whisper \file{small} from
\file{Systran/faster-whisper-small}; CTranslate2, CUDA device 0, FP16.
The menu's \file{en} or \file{de} is passed explicitly. Automatic language
detection is disabled.
\item \textbf{Answers:} local Ollama model \file{llama3.2:3b}, 4,096-token
context. The server requires at least 99\% reported GPU allocation.
\file{ollama==0.6.2} is the Python client version, not the desktop application version.
\item \textbf{Female voices:} \file{en_US-kristin-medium} and \file{de_DE-ramona-low}.\\
\textbf{Male voices:} \file{en_US-mike-medium} and \file{de_DE-thorsten-high}.\\
Each needs its \file{.onnx} model and \file{.onnx.json} configuration.
Downloads come from \file{rhasspy/piper-voices}; menu choices select the profile.
\end{itemize}
ONNX is a model file format; ONNX Runtime is the software that runs it.
CUDA/cuDNN libraries are installed as Python packages. A suitable NVIDIA driver
is still required. The shared \file{cuda_runtime.py} prepares DLL paths for
both server and preflight. No extra Python dependency was added by this cleanup.
