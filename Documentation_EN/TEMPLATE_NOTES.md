# Template source and local use

- Template: **Technical Document Template** by Overleaf.
- Source: https://www.overleaf.com/latex/templates/technical-document-template/mdgftpdfbvbs
- Gallery license: LaTeX Project Public License 1.3c.
- Original class: `ol-softwaremanual.cls`, version 1.1, 2021/05/17.
- SHA-256 of the unchanged class:
  `2eebfa3fd4a7a7cfa0187391715eee9f19a1f8e62ea62c897eeec8bc9eebc62b`.

The class supplies Roboto/Roboto Mono, paragraph spacing and the title-page
commands. EVA adds its own text wordmark, content, page settings and three
document entry points. The cheat sheet uses a smaller font and wider text area
to remain two pages.

Code examples use `listings` instead of the template's `minted`, allowing local
compilation without shell escape or Python/Pygments. Unrelated original sample
text, images and MATLAB examples are not part of this documentation.
